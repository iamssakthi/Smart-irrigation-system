About Project

Academic prototype overview

Project title

Design and Development of an Intelligent Sensor-Based Automated Irrigation System for Smart Agriculture Using Raspberry Pi and IoT Technology.

Objective

This project demonstrates a prototype irrigation control system that monitors soil moisture, applies hysteresis-based thresholds, and presents a live dashboard for monitoring and demonstration.

Important note

The implemented dashboard and control logic are simulated software and do not claim to be a physical sensor deployment. The Raspberry Pi and Wokwi ESP32 setups are documented as intended hardware and simulation pathways.
